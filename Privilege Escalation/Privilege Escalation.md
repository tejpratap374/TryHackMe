# Privilege Escalation
- **Privilege escalation is the process of moving from a lower-privileged account to a higher-privileged one on a system.**


## Types of Priv Esc
1. Vulnerability-Based escalation
2. Configuration-Based escalation


## Security Benchmarks and Frameworks
1. CIS (Centre for Internet Security) benchmarks
2. DISA STIGs (Defense Information Security Agency, Security Technical Implementation Guides)
3. NIST (National Institute of Science and Technology)


Manually Testing a host against these benchmarks can take a lot of time and can be hectic, we can make use of [[Automated Compliance Tools]].
